# Solid Connection 공개 실험 데이터

이 디렉터리는 개선된 Muzeel의 Solid Connection 홈 화면 실험을 요약한다.
운영 사이트의 JavaScript 본문과 이미지와 쿠키와 브라우저 프로필은 포함하지
않는다.

## 파일

| 파일 | 내용 |
|---|---|
| `actions.json` | 브라우저 MCP에서 확인한 13개 상호작용 |
| `results.json` | 원본과 공격적 개선판과 최종 안전 정책의 집계 수치 |
| `holdout.json` | 탐색과 분리한 회귀 시나리오 결과 |
| `environment.json` | 재현에 필요한 실행 환경과 정책 |
| `agent-run-20260814.json` | 실제 Muzeel AI Agent 실행 집계 |
| `validate_dataset.py` | 수치와 데이터 구조 검증기 |

## 검증

저장소 루트에서 다음 명령을 실행한다.

```sh
python3 experiments/solid-connection/validate_dataset.py
```

검증기는 다음 조건을 확인한다.

- 행동이 13개이며 허용된 안전 행동만 포함한다.
- 처리 전 크기에서 처리 후 크기를 뺀 값이 감소량과 같다.
- 함수 수가 실행 함수와 제거 함수의 합과 같다.
- 최종 분석 실패가 0개다.
- 다섯 개 회귀 시나리오가 원본과 처리본에서 모두 통과했다.
- 기능 손상 판정이 0건이다.

## 원본 스냅샷이 없는 이유

웹 응답 본문을 그대로 커밋하면 대상 사이트 코드와 이미지가 저장소에 복제된다.
이 공개 데이터는 방법과 집계 결과를 검토하기 위한 최소 자료만 제공한다.
실제 재현자는 자신이 권한을 가진 시점의 페이지를 새로 캡처해야 한다. 사이트가
변경되면 번들 이름과 함수 수와 감소율도 달라질 수 있다.
