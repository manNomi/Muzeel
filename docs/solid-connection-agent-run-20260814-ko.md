# Solid Connection Muzeel AI Agent 실행 결과

## 결론

2026년 8월 14일에 `https://www.solid-connection.com/` 홈 화면을 새로 캡처하고
Muzeel AI Agent를 실행했다. AI는 12개의 안전한 화면 상호작용을 선택했다.
정책 거부와 행동 실패와 다른 경로 이동은 모두 0건이었다.

처리 대상에서 4,084개의 함수를 찾았다. 브라우저 실행에서 1,180개의 함수가
관찰됐다. 관찰되지 않은 2,904개의 함수 본문을 비웠다. 전체 JavaScript 크기는
1,919,653바이트에서 1,487,171바이트로 줄었다. 감소량은 432,482바이트이며
감소율은 22.529%다.

이 결과는 운영 사이트에 배포한 결과가 아니다. 운영 응답을 읽기 전용으로
캡처한 뒤 로컬 스냅샷에서 계측과 제거와 검증을 수행했다.

## AI가 수행한 탐색

AI는 화면에서 관찰된 CSS 선택자만 사용했다. 어학 선택 목록을 열고 항목을
선택했다. 관심 국가 목록을 열고 항목을 선택했다. 학교 탭과 학교 목록 필터를
순환했다. 추가 필터 목록도 열고 항목을 선택했다.

링크와 로그인과 입력 필드와 제출 동작은 실행하지 않았다. 모든 행동의 전후
화면 상태와 정책 판단과 함수 실행 표식은 로컬 해시 연결 추적에 기록했다.
개인정보가 포함될 가능성이 있는 원본 추적은 공개 데이터에 넣지 않았다.

## 재현 명령

오늘 캡처한 것과 같은 형식의 스냅샷이 있을 때 다음 명령으로 실행할 수 있다.

```sh
python3 run_snapshot_agent.py \
  --site https://www.solid-connection.com/ \
  --site-id solid-connection-home \
  --snapshot-dir /absolute/path/to/snapshot \
  --driver /absolute/path/to/chromedriver \
  --planner-command "python3 -m muzeel_agent.adapters.codex_cli --timeout 75" \
  --output /absolute/path/to/new-output \
  --action-budget 12 \
  --time-budget 240
```

출력 디렉터리는 반드시 새 경로를 사용한다. 기존 추적에 새 실행을 이어 붙이지
않는다. 처리 파일을 채택하기 전에는 탐색에 사용하지 않은 시나리오로 원본과
처리본을 다시 비교해야 한다.

## 해석 범위

22.529%는 홈 화면과 허용된 12개 행동과 다섯 개 회귀 시나리오 안에서 확인된
수치다. 상세 페이지와 로그인 이후 화면과 결제나 개인정보 입력 기능의 안전성을
증명하지 않는다. 그런 화면을 처리하려면 별도의 권한과 스냅샷과 독립 회귀
시나리오가 필요하다.
