# Solid Connection 홈 화면 실험 보고서

## 목적

이 실험은 개선된 Muzeel이 최신 Next.js 페이지의 JavaScript를 분석할 수
있는지 확인하고 브라우저 에이전트가 선택한 상호작용으로 실행 코드를 충분히
노출할 수 있는지 살펴보기 위해 진행했다.

대상은 `https://www.solid-connection.com/`의 홈 화면이다. 운영 사이트의
코드나 데이터는 변경하지 않았다. 먼저 네트워크 응답을 로컬 스냅샷으로
저장한 뒤 계측과 제거와 회귀 검증은 모두 그 스냅샷에서 실행했다.

| 항목 | 값 |
|---|---|
| 실행 날짜 | 2026-08-13 |
| 운영체제 | macOS 15.7.4 arm64 |
| Python | 3.12.4 |
| Node.js | 23.10.0 |
| Chrome | 151.0.7922 계열 |
| 모바일 에뮬레이션 | iPhone X |
| 스냅샷 항목 | 79개 |
| JavaScript 파일 | 22개 |
| 원본 JavaScript 크기 | 1,919,566바이트 |

| 스냅샷 누락 정책 | 닫힘 처리 및 404 반환 |

쿼리 문자열을 보존한 이유는 서로 다른 API 요청과 번들 URL을 같은 리소스로
잘못 합치지 않기 위해서다. 스냅샷에 없는 요청은 실시간 인터넷으로 보내지
않았고 404로 닫았다. 따라서 처리본 검증 중 운영 서버 응답이 섞이지 않는다.

## 브라우저 에이전트 탐색

에이전트는 브라우저 MCP로 DOM과 접근성 이름과 화면 상태를 읽었다. 페이지
문구는 명령이 아니라 신뢰하지 않는 데이터로 취급했다. 로그인과 폼 제출과
외부 링크 이동은 제외하고 홈 화면 안에서 상태만 바꾸는 행동을 선택했다.

수행한 행동은 다음과 같다.

1. 상단 대학 탭에서 경희대와 중앙대와 인하대를 차례로 선택했다.
2. 어학 목록을 열고 IELTS를 선택했다.
3. 국가 목록을 열고 독일을 선택했다.
4. 전체 학교 목록에서 인하대와 경희대와 중앙대와 전체 필터를 선택했다.
5. 후기 콘텐츠와 하단 내비게이션이 보이도록 두 번 스크롤했다.

총 13개 행동이 계측된 로컬 스냅샷에서 재생됐다. 행동 실패는 0건이었다.
전체 행동 정의는
[`actions.json`](../experiments/solid-connection/actions.json)에 있다.

## 단계별 결과

안전 정책을 한 번에 정한 것이 아니라 오류를 관찰하면서 강화했다.

| 단계 | 분석 상태 | 감소율 | 검증 결과 | 판정 |
|---|---:|---:|---|---|
| 원본 Muzeel | 22개 중 16개 파싱 중단 | 20.06% | 기본 시나리오 4개 통과 | 분석 불완전 |
| 최신 파서 공격적 처리 | 22개 전체 분석 | 50.49% | 기능 5개 통과 | GTM 오류로 기각 |
| 외부 파일만 보존 | 분석 대상 전체 성공 | 36.75% | 기능 5개 통과 | Sentry 오류로 기각 |
| 외부 및 보호 런타임 보존 | 분석 대상 전체 성공 | 22.84% | 기능 5개 통과 | 공개 결과로 채택 |

공격적 처리의 높은 감소율은 성공 지표가 아니었다. Google Tag Manager와
Sentry 오류가 새로 발생했기 때문이다. 최종 결과는 절감량을 낮추더라도
외부 파일과 앱 번들 안의 보호 런타임을 유지했다.

보존했다.

## 독립 회귀 검증

탐색 때 선택한 값만 다시 검사하면 탐색 경로에 과적합될 수 있다. 따라서
탐색에서 사용하지 않은 JLPT와 호주 옵션을 포함한 시나리오를 별도로 만들었다.

| 시나리오 | 원본 | 처리본 | 화면 유사도 |
|---|---:|---:|---:|
| 탐색하지 않은 JLPT 선택 | 통과 | 통과 | 1.000000 |
| 탐색하지 않은 호주 선택 | 통과 | 통과 | 1.000000 |
| 대학 탭 순환 | 통과 | 통과 | 1.000000 |
| 전체 학교 필터 순환 | 통과 | 통과 | 1.000000 |
| 하단 스크롤 및 내비게이션 | 통과 | 통과 | 0.999969 |

기능 손상 판정은 0건이다. 최종 처리본의 콘솔 오류 수와 오류 종류는 각
시나리오의 원본과 같았다. 공통 오류는 스냅샷 환경에서도 원본부터 발생한
React hydration 오류와 닫힌 네트워크 요청의 404다.

## 해석

최종 결과는 홈 화면 범위에서 개선판이 기존보다 완전한 함수 분석을 수행하고
약 22.84%를 줄이면서 선택된 기능을 유지했다는 증거다. 전체 사이트에서
22.84%를 안전하게 제거할 수 있다는 뜻은 아니다.

학교 검색 결과와 상세 페이지와 로그인 이후 화면과 사용자별 기능을 처리하려면
각 상태를 별도 스냅샷과 행동 예산에 포함해야 한다. 운영 배포 판단에는 실제
사용자 트래픽을 반영한 장기 관찰과 성능 측정과 오류 모니터링이 추가로 필요하다.

## 공개 데이터 범위

저장소에는 행동 정의와 집계 결과와 환경 정보와 검증 시나리오만 포함한다.
대상 사이트의 JavaScript 원문과 이미지와 응답 본문과 브라우저 프로필은
재배포하지 않는다.
